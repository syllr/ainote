# Agent 面板

Agent 面板是与可以在你的项目中读取、写入和运行代码的 AI 代理交互的地方。它是 Zed 的 AI 代码编辑体验的核心——用于代码生成、重构、调试、文档编写和一般问题。

使用命令面板中的 `agent: new thread` 或点击状态栏中的 ✨ 图标打开它。

## 入门

如果首次使用 Agent 面板，需要配置至少一个 LLM 提供商或外部代理。你可以通过以下方式配置：

1. [订阅我们的 Pro 计划](https://zed.dev/pricing)，这样你就可以使用我们的托管模型
2. [使用你自己的 API 密钥](./llm-providers.html#use-your-own-keys)，来自 Anthropic 等模型提供商或 OpenRouter 等模型网关
3. 使用 [外部代理](./external-agents.html) 如 [Gemini CLI](./external-agents.html#gemini-cli) 或 [Claude Agent](./external-agents.html#claude-agent)

## 概述

配置了 LLM 提供商或外部代理后，在消息编辑器中输入内容并按 `enter` 提交。如果需要更多空间，使用 `shift-alt-escape` 扩展编辑器。

响应会流式显示，并显示模型正在使用 [哪些工具](./tools.html)。

## 创建新会话

默认情况下，Agent 面板使用 Zed 的第一方代理。

要选择另一个代理，转到 Agent 面板右上角的加号按钮，从内置的外部代理中选择一个。

## 编辑消息

你可以发送给模型的任何消息都是可编辑的。你可以点击包含你消息的卡片，使用调整后的提示和/或新的上下文块重新提交。

## 队列消息

当代理处于生成状态时发送的消息，默认会进入队列。

对于 Zed 代理，队列中的消息在下一个转换边界发送，通常在工具调用和响应之间，而对于外部代理，消息在生成结束时发送。

你可以编辑或删除（单个或全部）队列中的消息。你还可以通过点击停止按钮或点击队列消息上的"发送现在"（双击回车）立即中断代理。

## 检查点

每次模型执行编辑时，你应该在消息顶部看到一个"恢复检查点"按钮，允许你将代码库返回到该消息之前的状态。

即使你在编辑中途中断线程，检查点按钮也会出现，因为这可能是一个你意识到代理没有朝着正确方向发展并想要回退的时刻。

## 上下文菜单

在线程视图中右键点击任何代理响应以访问包含以下操作的上下文菜单：

- **复制选择**: 复制当前选中的文本为 Markdown（选中文本时可用）
- **复制此代理响应**: 复制你右键点击的代理响应的完整文本
- **滚动到顶部/滚动到底部**: 根据你的当前位置滚动到线程的开头或结尾
- **将线程打开为 Markdown**: 在新选项卡中将整个线程作为 Markdown 文件打开

## 导航线程

在长时间对话中，使用面板底部的滚动箭头按钮跳转到最近的提示或线程的最开始。当线程窗格获得焦点时，你还可以使用箭头键、Page Up/Down、Home/End 和 Shift+Page Up/Down 在消息之间跳转。

当焦点在消息编辑器中时，你还可以使用 `ctrl-pageup`/`ctrl-alt-pageup`、`ctrl-pagedown`/`ctrl-alt-pagedown`、`ctrl-home`/`ctrl-alt-home`、`ctrl-end`/`ctrl-alt-end`、`ctrl-alt-up`/`ctrl-alt-up` 和 `ctrl-alt-down`/`ctrl-alt-down` 导航线程，或使用 `ctrl-alt-pageup`/`ctrl-alt-shift-pageup` 和 `ctrl-alt-pagedown`/`ctrl-alt-shift-pagedown` 在你的提示之间跳转。

## 导航历史

要快速浏览最近更新的线程，当焦点在面板编辑器上时使用 `cmd-shift-j`/`shift-alt-j` 绑定，或点击面板右上角的菜单图标按钮。这将打开一个下拉列表，显示你的六个最近更新的线程。

要查看所有历史对话，从同一菜单中选择"查看全部"选项，或通过 `cmd-shift-h`/`ctrl-shift-h` 绑定。

线程标题根据对话内容自动生成。你也可以通过点击标题并输入内容手动编辑它们，或通过点击面板右上角省略号菜单中的"重新生成线程标题"按钮重新生成。

## 跟随代理

通过点击面板左下角的十字准星图标跟随代理，当它读取和编辑文件时。你也可以在提交消息时按住 `cmd`/`ctrl` 自动跟随。

## 获取通知

如果你向 Agent 发送提示，然后将 Zed 放在后台，可以选择在生成完成时收到通知：

- 屏幕右上角出现的视觉通知
- 声音通知

这些通知可以单独使用或组合使用，你可以使用 `agent.notify_when_agent_waiting` 和 `agent.play_sound_when_agent_done` 设置键来自定义，包括完全关闭两者。

## 审查更改

一旦代理对你的项目进行了更改，面板将显示它编辑了哪些文件、多少个文件以及编辑了多少行。

要查看具体编辑了哪些文件，展开显示在消息编辑器上方的手风琴条，或点击"审查更改"按钮（`shift-ctrl-r`/`ctrl-shift-r`），这将打开一个特殊的多缓冲区选项卡，其中包含所有更改。

你可以接受或拒绝每个单独的更改块，或接受或拒绝代理所做的所有更改。

编辑差异也出现在单缓冲区中。如果你的活动选项卡有 AI 编辑的内容，你会看到带有与多缓冲区中相同的接受/拒绝控制的差异。你可以通过 `agent.single_file_review` 设置关闭此功能。

## 添加上下文

代理可以搜索你的代码库以找到相关的上下文，但明确提供它会改善响应质量并减少延迟。

通过在消息编辑器中输入 `@` 来添加上下文。你可以提及文件、目录、符号、以前的线程、规则文件和诊断。

当你从缓冲区中复制多行代码选择粘贴时，Zed 会自动将其格式化为带有文件上下文的 @ 提及。要粘贴不带此自动格式化的内容，使用 `cmd-shift-v`/`ctrl-shift-v` 直接粘贴原始文本。

### 选择作为上下文

此外，你还可以在缓冲区或终端中选择文本，并通过使用 `cmd->`/`ctrl->` 键位绑定、运行 `agent: add selection to thread` 操作，或在消息编辑器中的 `+` 菜单中选择"选择"项，将其作为上下文添加。

### 图像作为上下文

对于支持视觉模型的提供商，也可以在提示中附加图像。OpenAI GPT-4o 及更高版本、Anthropic Claude 3 及更高版本、Google Gemini 1.5 和 2.0，以及 Bedrock 视觉模型（Claude 3+、Amazon Nova Pro 和 Lite、Meta Llama 3.2 Vision、Mistral Pixtral）都支持图像输入。

要添加图像，你可以通过在项目目录中搜索来提及它，或直接从文件系统拖放到 Agent 面板消息编辑器中。也支持复制图像并粘贴。

## Token 使用

Zed 在面板消息编辑器中靠近配置选择器的地方显示当前活动线程正在使用的 token 数量。

当你接近模型的上下文窗口时，消息编辑器上方会出现一个横幅，建议使用当前线程的摘要并添加为上下文开始新线程。你也可以在任何时候通过 Agent 选项菜单中的"从摘要新建"按钮，或简单地在新线程中 `@-提及` 过去的线程来执行此操作。

## 更改模型

配置了 LLM 提供商——无论是通过 [自定义 API 密钥](./llm-providers.html) 还是通过 [Zed 的托管模型](./models.html)——之后，你可以通过点击消息编辑器中的模型选择器或使用 `cmd-alt-/`/`ctrl-alt-/` 键位绑定在它们之间切换。

> 同一个模型可以通过多个提供商提供——例如，Claude Sonnet 4.5 通过 Zed Pro、OpenRouter、Anthropic 直接提供，等等。确保你为想要使用的模型选择了正确的模型**提供商**，由模型选择器左侧的徽章表示。

### 收藏模型

你可以通过模型选择器将特定模型标记为收藏，通过悬停时出现的星形图标按钮，或通过你的设置中的 `agent.favorite_models` 设置键。

使用 `alt-tab`/`alt-l` 在不打开模型选择器的情况下循环浏览你的收藏。

## 使用工具

Agent 面板支持工具调用，这启用了代理式编辑。Zed 包含用于搜索你的代码库、编辑文件、运行终端命令等的几个 [内置工具](./tools.html)。

你还可以通过 [MCP 服务器](./mcp.html) 扩展可用的工具集。

### 配置文件

配置文件充当工具的分组方式。Zed 提供三个内置配置文件，你可以创建任意数量的自定义配置文件。

#### 内置配置文件

- `Write`: 一个允许 LLM 写入文件和运行终端命令的工具配置文件。这个配置文件基本上启用了所有内置工具。
- `Ask`: 一个只读工具配置文件。最适合询问关于代码库的问题，而不必担心代理做出更改。
- `Minimal`: 一个没有任何工具的配置文件。最适合与 LLM 进行一般对话，无需了解你的代码库。

你可以通过点击配置文件选择器按钮 > `配置` 按钮 > 你想要检查的配置文件来探索每个配置文件中启用的确切工具。

或者，你也可以通过命令面板（运行 `agent: 管理配置文件`）或直接使用键位绑定 `cmd-alt-p`/`ctrl-alt-p` 访问配置文件管理模态框。

使用 `shift-tab`/`shift-tab` 循环浏览可用配置文件，而不打开模态框。

#### 自定义配置文件

你也可以通过 Agent 配置文件模态框创建自定义配置文件。从那里，你可以选择 `添加新配置文件` 或使用自定义名称和首选工具集分叉现有配置文件。

还可以覆盖内置配置文件。在 Agent 配置文件模态框中，选择一个内置配置文件，导航到 `配置工具`，并重新排列你想要保留或删除的工具。

Zed 将使用与覆盖的默认配置文件相同的配置文件名称在你的设置中存储此配置文件。

所有自定义配置文件都可以通过 UI 或手动在设置文件中的 `agent.profiles` 键下编辑。

要删除自定义配置文件，打开 Agent 配置文件模态框，选择要删除的配置文件，然后点击删除按钮。

### 工具权限

> **注意**: 在 Zed v0.224.0 及更高版本中，工具批准由 `agent.tool_permissions.default` 控制。在早期版本中，它由 `agent.always_allow_tool_actions` 布尔值（默认 `false`）控制。

Zed 的 Agent 面板提供 `agent.tool_permissions.default` 设置来控制工具批准行为：

- `"confirm"`（默认） — 在运行任何工具操作之前提示批准
- `"allow"` — 自动批准工具操作而不提示
- `"deny"` — 阻止所有工具操作

当代理请求权限时，确认菜单包括允许或拒绝一次的选项，以及"对...始终"选择，这些设置添加了工具级别的默认值。当 Zed 可以从输入中提取安全模式时，它还会提供基于模式的"对...始终"选择，这些选择添加了 `always_allow`/`always_deny` 规则。MCP 工具只支持工具级别的默认值。

即使设置为 `"default": "allow"`，每个工具的 `always_deny` 和 `always_confirm` 模式仍然被尊重 — 所以你可以自动批准大多数操作，同时阻止或限制特定操作。

了解更多关于 [工具权限如何工作](./tool-permissions.html)，如何进一步自定义它们以及其他详细信息。

### 模型支持

工具调用需要每个模型和模型提供商单独支持。因此，尽管有内置工具，某些模型可能无法选择它们。如果你选择一个属于这种情况的模型，你应该看到"No tools"标签。

所有 [Zed 的托管模型](./models.html) 都原生支持工具调用。

### MCP 服务器

与内置工具类似，某些模型可能不支持给定 MCP 服务器中包含的所有工具。Zed 的 UI 会通过出现在模型选择器附近警告图标来通知你。

## 错误和调试

如果遇到错误或异常的 LLM 行为，使用 `agent: 打开线程为 markdown` 打开线程为 Markdown 并将其附加到你的 GitHub 问题中。

你还可以通过点击编辑器右侧的文件图标按钮（在拇指下方）将线程打开为 Markdown，当焦点在面板编辑器上时。

## 反馈

你可以对代理响应进行评分，以帮助改进 Zed 的系统提示和工具。

> 注意：对响应进行评分会将与该响应相关的数据发送到 Zed 服务器。有关 Zed 关于 AI 改进、隐私和安全的更详细信息，请参阅 [AI 改进](../ai/ai-improvement.html) 和 [隐私和安全](./ai/privacy-and-security.html)。**如果你不想数据保留在 Zed 服务器上，请不要评分**。我们不会在没有你明确评分响应的情况下收集改进我们代理功能的数据。

要帮助改进 Zed 的系统提示和工具，在每次响应末尾使用向上/向下控件对响应进行评分。如果是向下评分，会出现一个新的文本区域，你可以添加更多关于发生了什么的详细信息。

你可以在代理响应后任何时间提供反馈，并在同一线程中多次提供反馈。
