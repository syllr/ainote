# 编辑代码

Zed 提供工具来帮助你高效地编写和修改代码。本节涵盖与语言服务器协同工作的核心编辑功能。

## 本节内容

- **[代码补全](../completions.html)** — 来自语言服务器的自动完成和 AI 驱动的编辑预测
- **[代码片段](../snippets.html)** — 使用制表位插入可重用的代码模板
- **[格式化和 Linting](../configuring-languages.html#formatting-and-linting)** — 配置自动代码格式化和 Linter 集成
- **[诊断和快速修复](../diagnostics.html)** — 查看错误、警告并应用语言服务器的修复

## 这些功能如何协同工作

当你编辑代码时，Zed 结合来自多个来源的输入：

1. **语言服务器** 根据项目的类型和结构提供补全、诊断和快速修复
2. **编辑预测** 根据你最近的更改、访问过的文件和光标位置建议多字符或多行更改
3. **多缓冲区** 让你在一个操作中跨文件应用更改

例如，你可能会：

- 使用语言服务器的重命名重构功能重命名函数
- 在显示所有受影响文件的多缓冲区中查看结果
- 使用多光标在所有位置进行额外编辑
- 如果出现问题，立即获得诊断反馈
