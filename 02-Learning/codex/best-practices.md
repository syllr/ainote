# Codex 最佳实践

## 提示词设计原则

### 1. 提供清晰的上下文

在提示词中包含足够的上下文信息，帮助模型理解需求。

**好的示例**:
```
写一个 Python 函数，从 CSV 文件中读取数据并返回前 5 行。
CSV 文件包含以下列: name, age, email。
```

### 2. 指定编程语言和风格

明确指定你想要的编程语言和代码风格。

**示例**:
```
用 Python 写，遵循 PEP 8 规范。
```

### 3. 分步骤解决复杂问题

对于复杂任务，可以分解成多个步骤。

## 代码审核

始终审核生成的代码：
- 检查安全性问题
- 验证逻辑正确性
- 测试边缘情况
- 确保符合项目规范

## 安全注意事项

⚠️ 重要安全提示：

1. 不要在生产环境中直接使用未审核的生成代码
2. 注意检查潜在的安全漏洞（SQL注入、路径遍历等）
3. 避免生成处理敏感数据的代码
4. 遵守开源许可要求

## 效率技巧

1. 使用特定的、详细的提示词
2. 提供示例输入输出
3. 要求代码包含注释
4. 迭代优化提示词
