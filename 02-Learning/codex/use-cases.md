## 自然语言转代码

将自然语言描述转换为代码：

**示例**:
```
输入: "写一个 Python 函数，计算斐波那契数列"
输出:
def fibonacci(n):
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)
```
